# GUARDIAN OS

## Proactive Last-Mile Risk & Workload Intelligence

Guardian OS is an independent AI operations control plane prototype for
detecting operational disruptions, assessing network risk, simulating
counterfactual interventions, executing selected responses, and measuring
their outcomes.

## Core Control Loop

SENSE → UNDERSTAND → SIMULATE → DECIDE → ACT → MEASURE

## Build Strategy

### BUILD IT
Local-first development using open-source and locally runnable tooling.

### SHIP IT
AWS deployment using managed services such as:

- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- Amazon EventBridge
- AWS Step Functions
- Amazon Bedrock
- AWS Amplify

## Data

The prototype uses synthetic/simulated operational data.

It does not use Amazon proprietary or internal operational data.
